# Project

## Name: M14N

M14N is a numeronym (like i18n/l10n). The "14" stands for the 14 characters between the first and last letter.

It is a double easter egg:
- **Mykhailo Dorokhin** — the author (M + 14 chars + N)
- **Music Malfunction** — the project spirit (M + 14 chars + N)

Do not explain this in public docs or READMEs. M14N is enough.
