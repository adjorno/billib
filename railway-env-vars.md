# Railway Environment Variables

Set these in Railway Dashboard → Variables

## Build Configuration
- `RAILPACK_GRADLE_VERSION=9.2.1`
- `RAILPACK_JDK_VERSION=21`

## Database Configuration (Railway PostgreSQL)

**Railway PostgreSQL service**: `Postgres-93e4`

Set these environment variables in Railway Dashboard → Variables (Service: billib):

- `DATABASE_URL` - JDBC connection URL (uses Railway internal networking)
  - Format: `jdbc:postgresql://Postgres-93e4.railway.internal:5432/railway`
- `DATABASE_USERNAME` - PostgreSQL username
- `DATABASE_PASSWORD` - PostgreSQL password (see Railway dashboard)

### Notes:
- Database uses Railway's internal networking (`.railway.internal` domain)
- Only accessible from within Railway infrastructure
- Migrations run automatically on deployment (V2 schema - non-partitioned)
- Connection details are auto-generated by Railway
- **DO NOT** commit passwords or connection strings to git

### How to Get Credentials:
1. Go to Railway Dashboard
2. Select the `Postgres-93e4` service
3. Go to Variables tab
4. Copy values for `PGUSER`, `PGPASSWORD`, `PGDATABASE`
5. Set them in the `billib` service environment variables
